Mental Health & Wellbeing

A three-page website with information, tips and a sharing-form layout.

Individual project · Front End Development · Year 1, Semester 1

About this project

I made this website for Front End Development. It has a home page, an information page and a sharing-form page, with small interactions such as a greeting and a pop-up tips panel. It is a school project about presenting information, rather than a mental-health support service.

What I worked on

  • Built the home, information and sharing-form pages.
  • Added a greeting that changes with the time of day and a button to return to the top.
  • Included mood-selection checks and a live character count in the form.

The idea

The aim was to make three connected pages and practise adding interactions to an information-based website.

How I put it together

Breaking up the information

The home page uses topic cards, while the information page has questions that visitors can expand to read more.

Adding small helpful touches

I included a time-based greeting, a Quick Tips pop-up and a way to return to the top of the page.

Making the form respond

The form uses several types of input and shows a character count as someone types. It is a front-end exercise and does not send support requests.

How it turned out

Reflection

This project gave me practice adding behaviour to a website, rather than only arranging text and images. The greeting, pop-up tips and character counter are small features, but each responds in a different way. Working on them helped me connect what appears on the page with the JavaScript behind it.

I also worked with several ways of presenting information: cards, expandable questions and form controls. Having those on connected pages gave me a chance to think about how someone moves through a site. It is an early example of my interest in both how an interface looks and what happens when someone uses it.
