Zero-Waste Lifestyle

Putting everyday zero-waste ideas into a simple three-page website.

Individual project · Front End Development · Year 1, Semester 1

About this project

This school project uses HTML and CSS to present zero-waste ideas. I made a home page, an aspirations page and an about page, with a shared look across all three.

What I worked on

  • Built three linked pages with a shared stylesheet.
  • Used CSS Grid and Flexbox to arrange cards, images, tables and links.
  • Added a layout change for smaller screens.

The idea

The assignment was to organise information about zero-waste habits across three connected pages.

How I put it together

Keeping the pages familiar

I used the same header, navigation and styling so the pages felt like parts of one website.

Choosing layouts for the content

The home page uses cards for the five Rs. The aspirations page uses a goals table, and the about page includes a timeline-style table.

Working with different screen sizes

I used Grid, Flexbox and a mobile breakpoint to arrange the content for wider and narrower screens.

Visual walkthrough

How it turned out

The finished coursework website has three pages with shared navigation and different ways to display information, from cards to tables.

Reflection

This project gave me practice organising more than one page at a time. A shared header and stylesheet helped connect the pages, while the content on each page needed a slightly different arrangement. Working with cards, tables and images let me try different ways of making a page feel organised.

The smaller-screen layout was another part of that exercise. Content that has plenty of room on a desktop needs a different arrangement when the space becomes narrower. This project forms part of my foundation in HTML and CSS, especially using shared styles and layout tools across a small website.
