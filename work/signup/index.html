Sign-up form

A small exercise in putting together a clear sign-up form.

Individual practical · Front End Development · Year 1, Semester 1

About this project

This was a take-home Front End Development practical using HTML and Bootstrap. I focused on the layout of a sign-up form, with fields and controls for different kinds of information.

What I worked on

  • Built the sign-up form page in HTML and styled it with Bootstrap.

The idea

The exercise was to build a labelled form and practise using Bootstrap to arrange and style the controls.

How I put it together

Using different controls

The form combines text, email and password fields with a country list, radio options and a checkbox.

Keeping a clear order

I placed the labels beside their fields in a single-column layout, with the sign-up button at the end.

Visual walkthrough

How it turned out

The result is a form-layout exercise where visitors can try entering text and making selections. This portfolio version does not create accounts.

Reflection

Although this was a small practical, it gave me a focused way to work with a common part of many websites. Text fields, dropdowns, radio buttons and checkboxes all collect information differently, so arranging them on one page was useful practice with HTML forms and Bootstrap.

The single-column layout also gave the exercise a clear order. Labels, spacing and the position of the button all contribute to how the form reads. I see this as a smaller piece of work that shows some of the basics behind the larger websites in my portfolio.
