Retail Data Explorer

Finding and sorting retail data through a simple text menu.

Individual project · Fundamentals of Programming 2 · Year 1, Semester 2

About this project

For Fundamentals of Programming 2, I worked on a JavaScript program that retrieves and displays retail transaction data. The assignment provided the data service and dataset; my work was on the menu, requests and results.

What I worked on

  • Built the text menu and the way results are displayed.
  • Used asynchronous requests to get the data.
  • Sorted transactions and calculated category averages.

The idea

The idea was to let someone choose a menu option and get a useful view of the retail data.

How I put it together

Starting with a simple menu

The menu lets someone view records, see category averages, look up payment methods, filter results or find the highest transaction.

Getting the data ready

The program retrieves data from the supplied service before sorting it or calculating averages for the selected option.

Being clear about the result

The fifth option finds the category of the highest single transaction. It is a different question from finding the category with the highest total sales.

Visual walkthrough

How it turned out

The program has five data options and an exit option. The images below show its text output in a format that is easier to read on this website.

Reflection

This assignment let me focus on what happens to data before it reaches the person using a program. Retrieving records was only one part of the task; the program also needed to sort them, work out averages and display the results clearly. It gave me practice bringing those steps together through JavaScript.

The text menu made the project quite different from my visual-design work. Without images or a full webpage layout, the order and wording of the results carry more of the explanation. It is a useful example of my programming foundation and the care needed to describe exactly what a calculation is showing.
