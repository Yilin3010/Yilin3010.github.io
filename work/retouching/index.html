The Art Room — portrait & layout

Following a portrait from an old photograph to a framed webpage design.

Digital Visual Design · Year 2, Semester 1 · Class activity

About this project

This Digital Visual Design class activity brings together the original brown-toned portrait, a blue-background version, a wooden-frame presentation and The Art Room webpage design. Showing them together makes it easier to see how the same image carries through the work.

What I worked on

  • Worked on the class activity connecting the portrait’s presentation with a larger webpage layout.
  • Brought the original, blue-background, framed and webpage versions together in this portfolio.

The idea

The activity explored how a portrait could be presented in different ways and then used as part of a webpage design.

How I put it together

Starting with the original

The brown-toned photo sits alongside the blue-background version so the changes can be seen together.

Putting the portrait into a page

The framed image appears in The Art Room layout with a heading, text, navigation and another crop of the portrait.

Visual walkthrough

How it turned out

The gallery shows the four related stages together, from the original photograph to The Art Room layout.

Reflection

What stands out when these pieces are shown together is how the same portrait can feel different in each setting. The brown-toned photograph, blue background and wooden frame each change its presentation. Seeing the versions side by side gives the activity more context than showing only the final layout.

The webpage composition also places the image in a different role. It becomes one part of a page alongside headings, text and navigation, rather than an image on its own. This activity gave me practice looking at both the presentation of an individual image and how it sits within a larger design.
